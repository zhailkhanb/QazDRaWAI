# QAZ DRAW AI ✎

Қазақша сурет салу және суретті нейрожеліге тапқызу ойыны. Тегін, API кілтінсіз, серверлік есептеусіз жұмыс істейді.

## Ойнау

- Жеке ойын: 6 раунд, әр раундқа 20 секунд.
- Топтық ойын: бір телефонда/компьютерде 2–4 ойыншы кезектеседі, әрқайсысына 3 раунд. Бұл онлайн көпқолданушылық режим емес.
- Суретті саусақпен не тінтуірмен салыңыз. ЖИ 8 санат арасында болжам жасайды.
- Дұрыс танылса: 100 негізгі ұпай + қалған әр секундқа 5 ұпай.
- Соңғы сызықты қайтару, тазалау, раундты өткізу, суреттер галереясы бар.
- Рекордтар тек осы браузердің localStorage жадында сақталады. Тізім бір раундқа шаққандағы орташа ұпаймен реттеледі.

## Сайтты GitHub Pages арқылы ашу

1. Репозиторийде **Settings → Pages** бөліміне кіріңіз.
2. **Build and deployment → Source → Deploy from a branch** таңдаңыз.
3. **main**, **/ (root)** таңдаңыз да, **Save** басыңыз.
4. GitHub жариялау біткен соң Pages бөліміндегі сайт сілтемесін ашыңыз.

Күтілетін мекенжай: https://zhailkhanb.github.io/QazDRaWAI/
Бұл мекенжай Pages қосылып, жариялау аяқталғаннан кейін ғана жұмыс істейді.

## Компьютерде іске қосу

Python 3 орнатылған болса, осы папкада:

```sh
python3 -m http.server 8000
```

Сосын http://localhost:8000 ашыңыз. `index.html` файлын жай екі рет басып ашу ES module шектеулеріне байланысты жұмыс істемеуі мүмкін.

## Қандай нейрожелі?

`model.js` ішінде шағын **RBF (radial basis function) нейрожелісі** бар:

1. Сызықтарды өлшемі мен орналасуына тәуелсіз қалыпқа келтіру.
2. Суреттен 24×24 арақашықтық өрісін алу.
3. Жасырын қабатта 96 жасанды прототиппен Gaussian активацияларын есептеу.
4. Әр санаттың ең жоғары үш активациясының орташа мәні арқылы 8 шығысты есептеу.

Санаттар: күн, үй, ағаш (шырша), балық, жұлдыз, қолшатыр, кесе, шеңбер.

**Бұл тәжірибелік прототип.** Адамдар салған үлкен деректер жиынында оқытылмаған, Quick Draw моделіне тең емес. Еркін қолтаңба, қиғаш сурет, күрделі бөлшектер тануды нашарлатуы мүмкін. Шеңберді күн деп тану сияқты шатасулар болуы мүмкін. Пайыздар — салыстырмалы активациялар, калибрленген сенімділік емес. Бос сурет танылмайды. Танушыға тапсырма/мақсат берілмейді: модель тек салынған сызықтарды көреді.

Нейрожелі браузерде орындалады; суреттер желіге жіберілмейді. Қосымша сыртқы тәуелділік жоқ. Қаріп үшін Google Fonts жүктелуі мүмкін; желі болмаса жүйелік қаріп қолданылады.

## Тексеру

Node.js 20+:

```sh
npm test
```

Тесттер: бос енгізу, 40 жаңа жасанды үлгі, жылжыту/масштабтау инварианттығы, болжам ұпайларының дұрыстығы. Бұл тесттер адамның еркін салған суреттеріне немесе браузердегі толық ойынға дәлдік кепілдігін бермейді.

## Файлдар

- `index.html` — қазақша интерфейс
- `style.css` — бейімделетін дизайн
- `app.js` — ойын, таймер, кезектесу және ұпай
- `model.js` — тәжірибелік RBF нейрожелісі
- `model.test.js` — модель тесттері

## Келесі даму бағыты

Тануды жақсарту үшін лицензиясы тексерілген нақты қол суреттерінде оқытылған модельді қосу және браузерлерде/телефондарда қолмен тестілеу керек. Қазіргі топтық режим бір құрылғыда ғана жұмыс істейді.
