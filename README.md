# QAZ DRAW AI v2 — DoodleNet

Алғашқы нұсқадағы жасанды RBF прототиптерін салыстыру алынып тасталды. Бұл нұсқа нақты Quick Draw суреттерінде оқытылған DoodleNet CNN моделін пайдаланады.

## Жаңарту

ZIP-ті ашып, ішіндегі **барлық файлдарды** репозиторийдің түбіне Upload files арқылы жүктеңіз, бұрынғы аттас файлдарды ауыстырыңыз да Commit changes басыңыз. Тек `index.html` немесе `app.js` файлын ауыстыру жеткіліксіз: модель бірнеше модульден тұрады.

GitHub Pages қосулы болса, жариялау аяқталғанын күтіп, браузерде Ctrl+Shift+R басыңыз. Тақырыпта **V2 • 16 САНАТ** көрінуі керек.

Pages әлі қосылмаса: Settings → Pages → Deploy from a branch → main → / (root) → Save.

## ЖИ қалай қосылады?

- Модельдің салмақтары: **2 176 804 байт**, 6 convolution + 3 max-pool + 2 dense қабаты, 345 шығыс санаты.
- Модель браузердің Web Worker модулінде жұмыс істейді. TensorFlow.js кітапханасын жүктеудің орнына шағын JS inference қозғалтқышы сол салмақтарды есептейді.
- Сайт алдымен жергілікті `weights.bin` файлын тексереді. Ол жоқ болса, pinned jsDelivr CDN, одан кейін GitHub raw мекенжайынан жүктейді. Әр жүктеуге 30 секунд шек қойылған.
- Git blob SHA-1 бақылау сомасы мен файл өлшемі тексеріледі. Содан кейін модель бос енгізуде өзіндік тексеруден өтеді. Бұл өзіндік тексеру тану дәлдігін өлшемейді.
- **«● DoodleNet дайын»** көрсетілгенде ғана ойын басталады.
- Интернет/мектеп желісі CDN мен GitHub raw-ды бұғаттаса, анық қате және **Қайта жүктеу** батырмасы шығады. Жалған болжам немесе жасырын RBF fallback жоқ.
- Сурет сыртқы серверге жіберілмейді. Модель мен қаріпті жүктеуге арналған сұраулар ғана сыртқы желіге шығады.

Модель көзі:

Оны **weights.bin** деп атап, сайт файлдарымен бір папкаға орналастырыңыз/репозиторийге жүктеңіз. Қозғалтқыш өлшемі мен checksum-ы сәйкес келмеген файлды қабылдамайды. Бұл ZIP сыртқы модель салмақтарын қамтымайды; әдетте олар сайт ашылғанда автоматты жүктеледі.

## Ойын

- 16 қазақша тапсырма: күн, үй, ағаш, балық, жұлдыз, қолшатыр, кесе, шеңбер, алма, ай, бұлт, найзағай, кітап, үшбұрыш, шаршы, көзілдірік.
- Жеке жарыс немесе бір құрылғыда 2–4 ойыншы кезектесетін топтық жарыс.
- Әр ойыншыға бірдей ретпен 3, 6 немесе 8 тапсырма беріледі. Кезекті күткен ойыншы алдыңғы суретті көре алады; бұл бақылаумен ойналатын сыныптық режим.
- Раунд уақыты: 10 / 20 / 30 секунд. Ұпай: 100 + қалған уақыт үлесіне сай 0–100 бонус. Рекордтар раундқа шаққандағы ұпаймен реттеледі, таңдалған уақыт та көрсетіледі.
- Уақытсыз жаттығу, жасанды үлгіні көру, соңғы сызықты қайтару, тазалау, қолмен ЖИ-ге тексерту.
- Ойын нәтижесі, PNG суретті сақтау, Excel үшін UTF-8 BOM және `;` бөлгіші бар CSV экспорты.
- Дыбыстық белгіні қалауыңызша қосуға болады.

Танушыға мақсатты тапсырма берілмейді. Ол барлық 345 санат арасынан болжайды. Ойын мақсатымен сәйкес келген ең жоғары болжам кемінде 22% болып, екі рет қайталанса, раунд аяқталады. Пайыздар калибрленген дәлдік кепілдігі емес. Кесе үшін mug/coffee_cup/cup атаулары бір мағынаға келтіріледі; олардың ең жоғары ықтималдығы алынады.

Модель өздігінен жаңа суреттерде оқытылмайды. Болжамдардың ойынға кірмейтін кейбір атаулары ағылшынша көрсетіледі. Бұл Google Quick Draw ресми сайты емес, оның дәлдігіне тең деп уәде берілмейді.

## Іске қосу және тексеру

Python 3:
```sh
python3 -m http.server 8000
```
http://localhost:8000 ашыңыз. Екі рет басып ашылған `file://` мекенжайы модульдер мен Worker-ді жүктей алмауы мүмкін.

Node.js 20+:
```sh
npm test
```

14 тест: CNN convolution/pooling/dense/softmax математикасы; салмақ құрылымы; суретті қалыпқа келтіру; 345 атау мен 16 тапсырманың сәйкестігі; бос/бүлінген енгізу; топтық әділ кесте; ұпай; CSV; ЖИ дайын болғанша ойынды бұғаттау; ескі болжамдарды елемеу; бір рет ұпай беру; жаттығу және модель қатесі.

**Тексеру шегі:** осы әзірлеу ортасында сыртқы бинарлық модель салмақтарын жүктеу мен толық браузерлік тексеру қолжетімсіз болды. CNN құрылымы нөлдік салмақтармен, математикалық бөлшектері белгілі нәтижелермен тексерілді; нақты DoodleNet салмақтарындағы тану дәлдігі мұнда өлшенген жоқ. Мектептегі браузерде шеңбер, күн, үй сияқты суреттерді салып тексеріңіз.

## Файлдар

- `index.html`, `style.css`, `app.js` — интерфейс және ойын
- `cnn-worker.js` — модель жүктеу, checksum, фондық тану
- `model.js` — CNN есептеуі, суретті өңдеу, қазақша атаулар
- `classes.js`, `model-config.js` — модельдің санат реті және бекітілген нұсқасы
- `demos.js` — жаттығудағы үлгілер ғана; тануда пайдаланылмайды
- `game.js` — кесте, ұпай және CSV
- `*.test.js` — автоматты тексерулер
- `THIRD_PARTY_LICENSES.txt` — модель мен санаттардың авторлық мәліметтері
